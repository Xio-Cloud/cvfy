# CvFy JSON Builder Skill

This skill instructions file enables any AI agent (Claude, ChatGPT, Gemini, Cursor, Windsurf, Antigravity) to convert Markdown CVs or raw resume text into valid **CvFy JSON** format for live visualization on **[cv.xio.vn/create](http://cv.xio.vn/create)**.

---

## 1. Skill Purpose & Execution

When instructed to generate or convert a CV into CvFy JSON:
1. Parse the candidate's personal information, summary, work experience, education, projects, skills, and languages.
2. Structure the data into the exact `Cv` schema wrapped inside a top-level `"formSettings"` JSON key.
3. Ensure all dates are formatted as valid ISO 8601 strings (`"YYYY-MM-DDTHH:mm:ss.sssZ"`).
4. Output valid, raw JSON ready to be saved as `.json` and uploaded at `/create`.

---

## 3. Mandatory Conversion Rules

1. **Top-Level Wrapper**: All properties MUST reside inside `"formSettings": { ... }`.
2. **Date Format**: Property `from` and `to` MUST be ISO 8601 strings (e.g. `"2020-01-01T00:00:00.000Z"`). If currently employed, set `"current": true` and `"to"` to current UTC ISO date.
3. **Language Levels**: Property `level` inside `languages` MUST be strictly one of:
   - `"elementary"`
   - `"limited-working"`
   - `"professional-working"`
   - `"full-professional"`
   - `"native-bilingual"`
4. **Summary Markdown**: Property `summary` in `work`, `education`, and `projects` supports Markdown lists (`- Bullet point`) and bold text (`**Header**`).
5. **IDs**: Each item in `work`, `education`, and `projects` MUST have a unique `id` string (e.g., `"work-1"`, `"edu-1"`).

---

## 4. How to Import and Visualize

1. Save the JSON output generated by the AI agent to a file named `cv.json`.
2. Open **[cv.xio.vn/create](http://cv.xio.vn/create)** (or `http://localhost:3000/create`).
3. Scroll down to the bottom of the left sidebar (**CV Settings**).
4. Click **Upload CV settings (JSON)** and select `cv.json`.
5. The web app will instantly populate all fields and render your live interactive CV!
